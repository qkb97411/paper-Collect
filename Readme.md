# PaperCollected 项目

这是一个微信小程序项目，用于相纸收集和管理。

## 项目结构

- `pages/` - 小程序页面
- `subpkg/` - 分包页面
- `cloudfunctions/` - 云函数
- `utils/` - 工具函数

## 如何更新代码到 GitHub

### 每次修改后的标准流程：

```bash
# 1. 查看修改了哪些文件
git status

# 2. 添加所有修改的文件到暂存区
git add .

# 3. 提交修改（写一个有意义的提交说明）
git commit -m "修改说明：例如添加了新功能"

# 4. 推送到 GitHub
git push origin main
```

### 常用命令

- `git status` - 查看当前状态
- `git log --oneline` - 查看提交历史
- `git pull origin main` - 拉取最新代码（多人协作时使用）
